# Shroombrew community site

The website for [Shroombrew](https://shop.shroombrew.org/), a free Wii Shop Channel style
downloader for homebrew. Get Wii Points cards, link your Wii, send gifts and
browse the catalog.

Shroombrew is free, and so are its Wii Points. If someone charged you for it,
ask for your money back.

This repository is generated from the Shroombrew source (`community/`) by
`tools/build_pages.py`; edit the source, not these files. The live services
(cards, linking, gifts) run on the Shroombrew server.

Not affiliated with Nintendo.
